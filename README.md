## Currency Trading Platform

This is a personal project that I'm building to learn Python, programming, algorithms, and trading.

The goal is to create a program that can download historical Forex data, calculate technical indicators, backtest trading strategies, and eventually optimize them automatically.

This project is still a work in progress, and I'll continue adding new features as I learn more.

---

## Current Features

- Download historical Forex market data
- Calculate:
  - EMA
  - RSI
  - ATR
  - Bollinger Bands
- Generate trading signals
- Backtest trading strategies
- Save trade history to a CSV file
- Test different strategy parameters (currently in progress)
